# Pilot Readiness Checklist

- [ ] Firebase project, Authentication, custom claims, Firestore rules, Storage rules, and emulator tests approved.
- [ ] Organization, branch, roles, permissions, products, ingredients, recipes, suppliers, opening balances, and finance setup reconciled.
- [ ] POS devices, receipt printing, network-loss procedure, shifts, and daily reconciliation trained and tested.
- [ ] Trusted sale and ledger commands are live; no browser client can forge posted records.
- [ ] Backup export, restore rehearsal, support contact, incident process, and go-live rollback criteria approved.
- [ ] All lint, type-check, build, unit, integration, rule, and pilot smoke checks pass.

Do not sign off while any checked item is unsupported by evidence.
