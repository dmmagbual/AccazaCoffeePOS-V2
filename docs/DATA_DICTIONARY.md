# Data Dictionary

The typed data dictionary lists shared field names, meaning, validation, ownership, and consumers. It starts with tenancy, branch scope, code, and status fields and should grow with each shared field.
# Product catalog

Catalog records include product categories, products, variations, prices, modifier
groups/options, add-ons, combos, availability, and POS layouts. Organization scope
is required; branch scope is optional only for availability, layouts, and prices.
