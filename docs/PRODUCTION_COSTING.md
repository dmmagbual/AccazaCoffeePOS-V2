# Production Costing

Actual production cost is confirmed/provisional input cost from FIFO consumption plus packaging, utilities, labour, and other overhead. Cost per output unit is actual cost divided by actual yield; this naturally raises unit cost when yield is lower than planned.

Expected cost is recorded separately and variance is `actualCost - expectedCost`. Negative inventory allocations remain explicitly provisional and must be reconciled by the inventory workflow rather than silently changing a completed production record.
