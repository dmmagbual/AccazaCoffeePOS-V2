# Vision

Initial deployment uses the Business Setup Wizard (`/setup`) to collect and
validate the organization, first branch, master-data seeds, features, chart, and
owner details. Persisting this plan to Firebase is deferred to the trusted setup
command required by the P2 security boundary.

Product catalog configuration is organization-owned, with optional branch
availability and effective-dated pricing. Recipe costing and inventory consumption
remain centralized in their existing engines.

To build the most beautiful, fastest, and easiest-to-use Coffee Shop POS for independent cafés.

This system should help owners manage their business, help staff work efficiently, and provide customers with an outstanding experience.

---

# Core Principles

1. Simplicity
The system must be easy to learn.

2. Speed
A cashier should complete an order in under 10 seconds.

3. Beautiful Design
Every screen should feel modern and clean.

4. Reliability
The POS should continue working even when the internet is unavailable.

5. Scalability
The system should grow from one coffee shop to many branches.

6. Smart Business
The software should provide useful insights, not just reports.
